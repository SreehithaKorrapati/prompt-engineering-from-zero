# General prompt template

Copy, fill in the brackets, delete lines you don't need.

```
Act as [role].

Context:
[Who you are, background, what you're working on, why you need this]

Task:
[Exactly what you want done]

Constraints:
- Length: [e.g. under 200 words]
- Tone: [e.g. friendly, formal]
- Avoid: [things you don't want]

Output format:
[bullets / table / numbered steps / code / JSON]

If anything is unclear, ask me up to 3 questions before answering.
```

## Why the last line matters

Letting the model ask clarifying questions turns guesses into answers and teaches you what you left out.
