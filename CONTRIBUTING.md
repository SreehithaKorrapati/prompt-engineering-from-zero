# Contributing

Thanks for helping! This is a beginner-first project, so clarity matters more than cleverness.

## Ways to contribute

- Fix typos or unclear explanations
- Suggest a better weak/strong example
- Add a new lesson (open an issue first so we don't overlap)
- Share a prompt that failed and what fixed it

## Lesson format

Every lesson uses: **Technique, Weak prompt, Strong prompt, Why it works, Template, Try it yourself**.

## Rules

- Test prompts before submitting, and say which model you used
- Keep language simple and define jargon
- Don't paste copyrighted material
- Be kind. Questions from beginners are welcome.

## Pull requests

1. Fork and create a branch
2. Make your change
3. Open a PR describing what and why
