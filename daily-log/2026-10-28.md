# 2026-10-28: Day 1

**Topic:** Setup and the anatomy of a prompt

**What I tried:** Rewrote a vague question using task, context, constraints and format.

**Prompt that failed:** "Tell me about Python."

**Prompt that worked:** "I'm a beginner who knows basic Excel. Explain in 5 bullets why Python is useful for data analysis, using spreadsheet comparisons."

**What I learned:** The model guesses everything I leave out. More specific input gives a more useful answer.
